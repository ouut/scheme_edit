# VS Code 网页版 Scheme / Strict Paredit 专属极速快捷键手册

> **设计哲学**：
> 1. **彻底废除 Leader 两阶段**：纯单发（One-Shot），按一下立刻生效，绝不搞 Vim 模态！
> 2. **左手大拇指锚定 Alt（Mac: Option / ⌥）**：100% 避开浏览器关闭标签（`Ctrl+W`）、网页后退（`Alt+←`）和 macOS 调度中心（`Ctrl+方向键`）。
> 3. **零浏览器冲突特化**：针对 Chrome 浏览器内核特别优化，将易与浏览器菜单栏和地址栏冲突的键位升级为 **`Alt + X`**（无伤删词）与 **`Alt + \`**（智能排版），彻底杜绝浏览器菜单抢焦！
> 4. **精准领域特化**：绑定统一附加 `editorLangId == 'scheme'` 判定，**在 `.scm` 文件中拥有绝对最高优先级覆盖权**，不干扰其他日常开发。

### ⌨️ 键位分布与人体工学逻辑设计：

1. **最高频核心操作（45%）**：
   * **`Alt + K`（向外扩选）**：右手核心中指/食指下按，连按纵向扩张选中整组括号。
   * **`Alt + Enter` 或 `Ctrl + Enter`（发射求值）**：左手拇指锚定 Alt/Ctrl，右手一拍回车，立刻送入 Steel REPL 求值。
2. **高频包裹与吞吐（20% ~ 25%）**：
   * **`Alt + U`（圆括号包裹）** 与 **`Alt + Shift + U`（方括号包裹）**：左手同一键位通过 Shift 一体化掌控括号包裹。
   * **`Alt + J`（向右吞噬 Slurp）** 与 **`Alt + L`（向左吐出 Barf）**：右手食指/无名指左右开合，如同左右箭头一般直观吞吐。
3. **中频结构调整与定点导航（10% ~ 15%）**：
   * **`Alt + I`（向内收缩）**：与 `Alt + K` 呼应（I 向上/向内收，K 向下/向外扩）。
   * **`Alt + 1`（大步后退）** 与 **`Alt + 2`（大步前进）**：数字键 1 向左后退，2 向右前进。
   * **`Alt + 3`（选中顶级函数）**：一键直达最外层 `(define ...)`。
   * **`Alt + O`（脱壳解包 Splice）**：Open 打碎外层括号。
4. **低频辅助与微调（2% ~ 5%）**：
   * **`Alt + W`（向上跳出）** 与 **`Alt + S`（深度钻入）**：W 向上跳出外层，S 向下钻入内层。
   * **`Alt + X`（向后整块删除）**：eXterminate/剪切式抹除，100% 避开 Chrome 地址栏抢焦（原 `Alt+D`）。
   * **`Alt + \`（智能格式排版）**：对齐与排版，100% 避开 Chrome 菜单抢焦（原 `Alt+F`）。
   * **`Alt + H`（相邻参数对调）**：Handle swap 两项互换。
   * **`Alt + Shift + K`（列表切分）**：Knife cut 光标处一分为二。

## 🎯 17 个快捷键最终映射方案（按使用频率降序）

| 频级 / 占比 | 推荐快捷键 | 命令动作 | 心智助记符与手指分工逻辑 | 核心功能与效果 |
| --- | --- | --- | --- | --- |
| ⭐⭐⭐⭐⭐<br>(45%) | **`Alt + K`** | **向外扩选** (Expand) | 右手主键位纵向扩张 | 自动严丝合缝选中当前 `(...)`，连按扩大一层括号。配合求值极度丝滑！ |
| ⭐⭐⭐⭐⭐<br>(45%) | **`Alt + Enter`<br>或 `Ctrl + Enter`** | **发射求值** (Eval REPL) | 拇指锚定，右手一拍回车 | 将当前选中的代码立即送入 Steel REPL 运行并吐出结果。 |
| ⭐⭐⭐⭐<br>(25%) | **`Alt + U`** | **圆括号包裹** (Wrap Parens) | 核心主键区包裹 | `cards` $\rightarrow$ `(cards)`，单键把变量变成函数调用。 |
| ⭐⭐⭐⭐<br>(25%) | **`Alt + Shift + U`** | **方括号包裹** (Wrap Square) | Uniform brackets 方括号 | `x 10` $\rightarrow$ `[x 10]`，写 `let*` 局部变量和 `cond` 必备。 |
| ⭐⭐⭐⭐<br>(20%) | **`Alt + J`** | **向右吞噬** (Slurp) | 右手向右吸入 | `(a b) c` $\rightarrow$ `(a b c)`，右括号向右跨越一个元素。 |
| ⭐⭐⭐⭐<br>(20%) | **`Alt + L`** | **向左吐出** (Barf) | 右手向左吐出收缩 | `(a b c)` $\rightarrow$ `(a b) c`，右括号向左收缩，踢出末尾项。 |
| ⭐⭐⭐<br>(15%) | **`Alt + I`** | **向内收缩** (Contract) | 与 `Alt + K` 呼应收缩 | 与 `Alt+K` 呼应，基于历史栈回退，扩选过头随时往回收一级。 |
| ⭐⭐⭐<br>(10%) | **`Alt + 3`** | **选中顶级函数** (Defun) | 数字区 `3`（定点直达） | 无论光标藏在函数内部多深，一键选中最外层整个 `(define ...)`。 |
| ⭐⭐⭐<br>(10%) | **`Alt + O`** | **脱壳解包** (Splice) | Open 剥离外壳 | `(let () (expr))` $\rightarrow$ `(expr)`，打碎外层括号提取内部代码。 |
| ⭐⭐⭐<br>(10%) | **`Alt + 2`** | **大步前进** (Forward) | 数字区 `2`（向右前进） | 光标直接跨过右侧整组完整 S 表达式或参数。 |
| ⭐⭐⭐<br>(10%) | **`Alt + 1`** | **大步后退** (Backward) | 数字区 `1`（向左后退） | 光标直接跨过左侧整组完整 S 表达式或参数。 |
| ⭐⭐<br>(5%) | **`Alt + S`** | **深度钻入** (Down) | Step down 钻入 | 光标直接跳进当前括号内部最左侧第一个参数前。 |
| ⭐⭐<br>(5%) | **`Alt + W`** | **向上跳出** (Up) | Way out 跳出 | 光标跳到当前外层括号左侧前置位。 |
| ⭐⭐<br>(5%) | **`Alt + X`** | **向后整块删除** (Kill Sexp) | eXterminate 删词（免冲突） | 删掉光标右侧的一整组完整子表达式（不破括号，完全避开浏览器抢焦）。 |
| ⭐⭐<br>(5%) | **`Alt + \`** | **智能格式排版** (Indent) | 排版与对齐（免冲突） | 一键重新按 Lisp 缩进规范对齐当前 S 表达式代码块（完全避开 Chrome 菜单）。 |
| ⭐<br>(2%) | **`Alt + H`** | **相邻参数对调** (Transpose) | Handle swap 交换位置 | `(equal? a b)` $\rightarrow$ `(equal? b a)`，两项位置瞬间互换。 |
| ⭐<br>(2%) | **`Alt + Shift + K`** | **列表切分** (Split) | Knife cut 纵向切分 | `(a b \| c d)` $\rightarrow$ `(a b) (c d)`，从光标处把列表切成两半。 |
